How Constraints Interact
Hard Overrides Soft

If a hard constraint (e.g., HC-08 missing data) is triggered, soft constraint priorities have no effect. The hard constraint response takes precedence unconditionally.

Soft Shapes Priority Queue

Soft constraints influence which neighbourhoods are prioritised in the communication and response queue when multiple areas need attention simultaneously.

All Changes Audited

Any modification to soft constraint weights is recorded in the audit log with the user, timestamp, and previous/new values. Accountability is maintained.
